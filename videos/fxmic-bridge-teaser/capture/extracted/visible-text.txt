## Intent

Teaser for FXMic Bridge, an open-source macOS app that turns the teenage engineering
EP-2350 FX-MIC into a voice + gesture controller for the computer, and above all for
agentic software workflows (Claude Code, terminal agents).

Concept chosen: **"Chapter 8"** — the video plays as an unofficial new chapter of the
EP-2350 user guide, `((8)) talking to your agent`. It celebrates the product's design and
what teenage engineering made, and presents FXMic Bridge as an extension of their work.
Three beats + close:
1. hold the handle, red LEDs sweep (KITT), dictate;
2. white button picks a slot (e.g. `/review`), white LEDs show it in binary;
3. grey button sends it — a terminal shows Claude Code receiving the command;
4. close: "FXMic Bridge" wordmark, "open source · macOS", unofficial line.

Must read well muted (LinkedIn autoplays silent): callouts and on-screen text tell the story.

# FXMic Bridge gestures and commands

> The single reference for the EP-2350 FX MIC gestures and the actions behind them.
> App version: 0.3.0 (One-Pager 001), updated 2026-10-16.
> **Interface language:** English by default, changeable in Settings › General › Language (English, Italiano, Français, Español, Português, Deutsch, 中文, 日本語, Русский) or in `config.json` (`ui.language`).
> Everything is configured **per profile** in Settings › Profiles (or in `~/Library/Application Support/FXMicBridge/config.json`). This file describes the **defaults**. The reference code is `app/Sources/FXMicCore/Config.swift` (`Profile.defaults`) and `GestureRecognizer.swift` (`GestureSettings`).

## What each connection carries

| Connection | What it carries | What it enables |
|---|---|---|
| **USB-C** (data) | MicroPython serial console, plus power | All gestures and LEDs. The app installs a RAM-only agent (ADR-001). |
| **3.5 mm jack** | Analogue audio only | Voice only, through a USB audio interface (Settings › Audio). **No gestures** (a proposal for gestures via acoustic codes: [One-Pager 002](design-docs/onepager-002-jack-only-transport.md)). |
| **Mac keyboard** | — | Fallback push-to-talk: hold **right Option**. |

## The three buttons

### Orange: interaction modes (red LEDs, one per mode)
| Red LED | Mode | The dictation… |
|---|---|---|
| 1 | **Dictate** | is typed as spoken. |
| 2 | **Enhanced** | goes through the local LLM with the profile's "Enhanced" instruction. |
| 3 | **Command** | becomes an action: "make a bullet list", "new line", "delete the last word"…. The LLM returns keys and text from a closed list; dangerous shortcuts such as ⌘Q and ⌘W are blocked. |
| 4 | **Computer Use** | *not available yet*: the dictation only ends up in the history. |

**Tap:** next mode (only those enabled in the profile). **Long press:** back to the profile's default mode.

### White: command and skill slots (white LEDs in binary)
Up to **15 slots per profile**. The 4 white LEDs show the slot number in binary, with the top LED = 1, then 2, 4, 8. **All off = no slot.** The island always shows the slot's name.

| Slot type | What happens |
|---|---|
| **Run** | **Grey** runs the action at once: keys, text such as `/compact` + Return, and so on. |
| **Template** | The **next dictation** is placed into the slot's text in place of `{{text}}` (for example "Summarize: {{text}}"). |
| **LLM** | The **next dictation** is transformed by the LLM with the slot's instruction (for example "Rewrite as an email"). |

- **Tap:** next slot (none → 1 → 2 → … → none).
- **Double tap:** previous slot.
- **Long press:** no slot.
- **After use** the selection goes back to "no slot".
- **In Command mode** Template and LLM slots are ignored.

### Grey
- **Tap:** runs the selected "Run" slot; with no slot it presses **Return**.
- **Double tap:** undoes the last insertion (⌘Z, within 30 s, same app).
- **Long press:** retypes the last raw text; in terminals it presses **Esc**.
- **Pressed during dictation:** **edit the selection**, that is the dictated instruction is applied to the selected text.

## Handle and accelerometer
| Gesture | Action |
|---|---|
| Hold the handle, talk, release | Dictation, processed according to the active mode and slot |
| Quick double click on the handle | New line (⇧↩) |
| Short shake | Cancels the dictation in progress |
| Strong shake for at least 2 s | Clears everything (⌘A ⌫; in terminals Ctrl+E Ctrl+U) |

## Status pill and icon

- **Pill at the top:**
  - **MacBook (notch, Dynamic Island style, no border):**
    - left of the notch, the status dot: red with a **radar** effect while recording, pulsing white while processing;
    - on the right, the **recorded time**;
    - below, a line, for example "Recording · Enhanced · Summarize".
  - **Other screens:** a black pill under the menu bar with a thin light border: [dot] text [time].
  - Notices (mode or slot change, "Written", errors) show only the text. They fade in and out.
- **Menu bar icon:** it is **always the one you chose** (menu › Menu bar icon) and does not change while recording, because macOS already shows its own microphone indicator. The status is in the tooltip and in the first line of the menu.

## LEDs
| State | Red LEDs | White LEDs |
|---|---|---|
| Idle | Current mode (one LED) | Slot in binary, or off |
| Recording | **KITT**: one LED sweeping up and down | Unchanged |
| Transcribing and processing | Alternating 1+3 / 2+4 | Unchanged |
| Error | The 4 red LEDs blink for about 1 s | — |

- **LED map:** `device.ledMap` in `config.json` says which physical index matches [red 1…4, white 1…4]. The default `[0,1,2,3,4,5,6,7]` was verified on the device on 2026-10-16. Settings › Device › **Test LEDs** lights the LEDs one at a time in this logical order, so you can tell whether the map is right.
- **Animation speed:** set with `device.ledAnimationMs`, 120 ms by default.

## Configurable actions
| `type` | Effect |
|---|---|
| `key` (`keys`: list) | Sends combinations such as `cmd+a`, `shift+return`, `escape` |
| `text` (`text`) | Types the text; a trailing `\n` also presses Return |
| `cycleMode` / `resetMode` | Next / default mode |
| `nextSlot` / `previousSlot` / `clearSlot` | Slot navigation |
| `runSlot` | Runs the "Run" slot, otherwise Return |
| `undoLastInsertion`, `reinsertLast`, `cancel`, `editSelection`, `none` | As before |

## Gesture thresholds
| Parameter | Value |
|---|---|
| `tapMaxMs` · `doubleTapMs` · `longPressMs` | 450 · 300 · 600 ms |
| `handleClickMaxMs` · `handleDoubleClickGapMs` | 280 · 400 ms |
| `shakeThreshold` · `shakeHoldMs` · `shakeHoldToleranceMs` | 0.5 · 2000 ms · 400 ms |
